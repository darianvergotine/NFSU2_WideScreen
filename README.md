# NFSU2_FOVSettings
A small script mod allowing you to change the FOV of NFS Underground 2.

**INSTRUCTIONS**
- Extract the zip file and copy its contents to the "Scripts" folder in your Underground 2 game directory.
- Launch the game and press the hotkeys to adjust the FOV as indicated in the *ini file.
